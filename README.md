# Comparative-Evaluation-Of-Asynchronous-Programming-Models-In-Unity

A benchmark framework and comparative analysis of Coroutines, System.Threading.Tasks, and UniTask in Unity.

## Getting Started

### Prerequisites
* Unity 2022.3 LTS or higher.
* UniTask package installed (`Cysharp.Threading.Tasks`).

### Running the Benchmark
1. Clone the repository into your local machine.
2. Open the project in Unity.
3. Open the Test Runner window (`Window > General > Test Runner`).
4. Select the **PlayMode** and run `CoroutineVsUnitask`.
5. Exported JSON metrics will be automatically saved to the `Output/` directory in the project root.
